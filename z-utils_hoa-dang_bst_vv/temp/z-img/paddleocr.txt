Cài CUDA 12.6 + cuDNN 8.9.7 12.x
    sau khi cài cuda thì sẽ có folder "NVIDIA GPU Computing Toolkit"
        https://developer.nvidia.com/cuda-12-6-0-download-archive
    
    Giải nén cuDNN rồi copy tất cả file từ 3 thư mục vào CUDA toolkit:
        https://developer.nvidia.com/rdp/cudnn-archive
        📁 cudnn/bin/        →  copy vào  📁 CUDA/v12.x/bin/
        📁 cudnn/include/    →  copy vào  📁 CUDA/v12.x/include/
        📁 cudnn/lib/x64/    →  copy vào  📁 CUDA/v12.x/lib/x64/
